# BUILT TO ROLL — BJJ Performance Tracker

Android training diary for Brazilian Jiu-Jitsu and strength training.

## Planned features
- BJJ and strength training log
- Weekly training calendar and tournament countdown
- Sleep, recovery and readiness tracking
- Offline-first local data storage
- Czech user interface
